Penyebab gagal login di semua akun sebelumnya disebabkan oleh **konflik mekanisme Multi-Tenant Scoping otomatis** pada sistem model:

### 🔍 Penyebab Masalah
1. **Filter Tenant Prematur**: [UserModel.php](file:///d:/vibe-coding/sipelayan-desa/app/Models/UserModel.php) menginduk ke [BaseTenantModel.php](file:///d:/vibe-coding/sipelayan-desa/app/Models/BaseTenantModel.php). Pada implementasi sebelumnya, method `initialize()` langsung menyuntikkan klausa `WHERE users.village_id = 0` ke query builder setiap kali model dibuat saat belum ada sesi login aktif.
2. **Semua User Tidak Ditemukan**: Akibatnya, saat fungsi login mencari email pengguna, query yang dihasilkan menjadi `SELECT ... WHERE users.village_id = 0 AND users.email = '...'`. Baik Super Admin (`village_id = NULL`) maupun Admin/Operator/Warga (`village_id = 1`) tidak pernah cocok, sehingga sistem selalu memunculkan error *"Email atau password salah"*.
3. **Rate Limiting**: Percobaan login berturut-turut yang gagal memicu proteksi *Rate Limit* di IP lokal.

### 🛠️ Perbaikan yang Telah Dilakukan
1. **Refactoring [BaseTenantModel.php](file:///d:/vibe-coding/sipelayan-desa/app/Models/BaseTenantModel.php)**: Mengubah penambahan tenant filter menggunakan Model Events resmi CodeIgniter 4 (`$beforeFind`, `$beforeInsert`, `$beforeUpdate`, `$beforeDelete`).
2. **Pencarian Login Lintas Tenant**: Method `withoutTenantScope()` di [UserModel.php](file:///d:/vibe-coding/sipelayan-desa/app/Models/UserModel.php#L31-L39) kini dapat mengeksekusi query pencarian email secara akurat tanpa terhalang filter `village_id = 0`.
3. **Reset Cache & Rate Limit**: Cache aplikasi telah dibersihkan (`php spark cache:clear`).
